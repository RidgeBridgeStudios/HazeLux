# Ask before doing

- Deleting existing source files or test files.
- Modifying SQLite database schema (`hazelux/journal/schema.sql`).
- Changing rule schema or validation constraints in `hazelux/schema.py`.
- Adding new external dependencies to `pyproject.toml` or `requirements.txt`.
- Modifying packaging configurations (`debian/*`, `io.github.hazelux.Hazelux.yml`, `meson.build`).
- Pushing to `main` or force-pushing any remote branch.
